# Rocket_Control_Project

A button-triggered launch indicator with LEDs.

## What it does
While the button (pin 2) is released, a green LED stays on (ready/idle). When the button is pressed, the green LED turns off and two LEDs alternate every 250 ms to simulate a launch sequence / blinking warning.

## Wiring
- Button: pin 2 (INPUT)
- Green LED: pin 3
- Red LED: pin 4
- Red LED: pin 5
